# Reports UI kit — the monthly parent report

A written document, not a dashboard. One page, printable, sent at the end of each month.

- `index.html` — switch between two months to see how the same structure carries different news; prints clean.
- `Report.jsx` — `Letterhead`, `Block`, `Report`.

Structure, in this order, every month:
1. **How this month went** — prose, 3–5 sentences, specific about what changed.
2. **Topics** — `ProgressMeter`, three levels only (Secure / Building / Needs practice).
3. **Marks** and **Attendance** — `ScoreTable`, figures in mono, no commentary.
4. **To practise** — one `Callout`, one concrete instruction with a quantity.

Never: letter grades, class rankings, percentile language, praise adjectives, green.
