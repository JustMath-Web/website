Grouping container. Hairline border first; shadow only when the card is interactive.

```jsx
<Card tone="plain" rule><h3>Form 4 · Add Maths</h3><p>Weekly, 60 minutes.</p></Card>
<Card tone="sunken" padding={20}>Fee summary</Card>
```

Radius is 6px maximum — this brand is squared. Never combine `lift` with a static card, and never use `tone="invert"` more than once per screen.
