Every non-WhatsApp action on the site and in reports.

```jsx
<Button variant="primary" size="lg">See how it works</Button>
<Button variant="secondary">Download the report</Button>
<Button variant="ghost" href="#pricing">Fees</Button>
```

Variants: `primary` (ink fill), `secondary` (ink outline), `quiet` (hairline, for in-card actions), `ghost` (text with hover underline). Sizes sm 36 / md 44 / lg 52px — never below 44px on a mobile layout. Press state nudges 1px down; there is no scale bounce anywhere in this brand.
