Topic-by-topic progress in the monthly parent report.

```jsx
<ProgressMeter topic="Quadratic equations" level="secure" />
<ProgressMeter topic="Surds" level="practise" />
```

Three levels only: Secure (ink), Building (slate), Needs practice (ochre). Never red, never green — green means WhatsApp. Label the topic the way a parent would say it, not the syllabus code.
